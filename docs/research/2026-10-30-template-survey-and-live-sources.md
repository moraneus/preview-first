# Web-design "what goes with what" survey + live refresh sources

Date: 2026-10-30. Method: Part A = direct HTTP sweep of each live site's HTML (fonts via `@font-face`/woff2 names, colors via CSS vars / `theme-color` / inline `background`) plus visual knowledge of the site; items marked **(c)** have a fetch-confirmed signal, **(i)** are inferred and should be re-verified in a browser. Part B = every endpoint was hit with curl on 2026-10-30; status codes and payload fields recorded are real.

Gaps: gallery pages (Godly, Lapa, Land-book, SaaSpo, Framer/Webflow marketplaces, Mobbin, Dribbble) are JS-rendered or Cloudflare-gated, so the survey samples the *sites those galleries feature* rather than gallery listing pages. Button radius, card treatment and motion were not machine-extractable and are from visual knowledge (i). Three parallel template-survey sub-agents (SaaS/dev-tool/AI/dashboard; fintech/e-com/luxury/app; portfolio/agency/editorial/wellness/edu/nonprofit) were still running when this was written; their deeper per-template detail is not included.

### A.2 Synthesis by product type (winning combos → dated/clashing)

- **SaaS landing** — Win: (1) near-black `#08090a`–`#0a0a0a` bg, Inter/Geist/Suisse, one cool accent, 6–8px radius, 1px white/10 card borders, scroll fade-ups (Linear, Supabase); (2) white/`#fafafa` bg, Inter Display or Manrope tight headings, black pill/6px CTA, zero-shadow 1px cards (Attio, Cal.com); (3) warm off-white `#f7f7f4` + serif display + one earthy accent (Cursor, Ramp). Dated: blue→purple gradient hero with floating 3D blobs, drop-shadowed white cards on light gray, Poppins/Montserrat headings, 24px+ pill everything; glassmorphism on light backgrounds.
- **Developer tool** — Win: mono-black palette + Geist/Geist Mono (Vercel), or dark + brand green/coral + JetBrains/Commit/Geist Mono for code (Supabase, Raycast, Resend). Serif display + mono body pairing (Resend) is the current "premium" variant. Dated: VS-Code-dark-blue `#1e1e2e` everything, neon cyan accents, rainbow syntax screenshots as hero.
- **AI product** — Win: warm paper + serif + green/ochre (Cursor; Anthropic-style); or dark with subtle particle/mesh and Inter (OpenAI-like). Dated/clashing: purple-to-cyan "AI gradient", sparkle icons, glow-blurred orbs, Space Grotesk on gradient.
- **Dashboard/admin** — Win: shadcn zinc/stone/slate tokens, 8–10px radius, 1px borders, sidebar-01 pattern, Inter/Geist, charts in 1–2 brand hues on gray grid. Dated: card shadows + colored stat tiles in 4 saturated hues, Bootstrap-era 4px blue buttons, gradient sidebar.
- **Fintech** — Win: serif headline + grotesk body (Mercury: Tiempos+Arcadia), navy/indigo/violet accent (Stripe `#635bff`), soft shadows and pill CTAs; or warm neutral + acid lime (Ramp). Dated: bright `#0066ff` banking blue with teal gradient, stock-photo smiling people, heavy drop shadows.
- **E-commerce** — Win: neutral cream/white chrome + black pill CTA + photography as palette (Allbirds, Aesop); fonts geometric/grotesk sans. Dated: red "SALE" badges + multicolor category tiles, Lato/Open Sans, carousel-of-everything heroes.
- **Luxury brand** — Win: cream/black, sharp corners, hairline rules, ultralight serif (PP Editorial New, Canela) + hairline grotesk (Akkurat, Suisse), near-zero motion (Aesop, Oura). Clashing: rounded buttons, saturated accents, bounce animations, Montserrat.
- **Portfolio** — Win: dark or paper bg, one display face + mono labels, spring micro-interactions (Comeau); or ultra-minimal Swiss with Inter and underlined links. Dated: parallax full-screen slideshows, skill-percentage bars, Font Awesome icon grids.
- **Agency** — Win: brutalist black/white + condensed display + Lenis smooth scroll + WebGL (basement); or Studio-style editorial grid with serif. Dated: light glass cards, "we are a creative agency" hero with gradient blob, preloader counters.
- **Editorial/blog** — Win: condensed black display + grotesk body + hard rules (Verge); or classic serif body (Tiempos/Source Serif) on off-white. Dated: Medium clone (Charter + green), sidebar widget clutter.
- **Health/wellness** — Win: blush/cream + warm orange/coral + geometric sans + 16–24px radii (Headspace); or black + ultralight serif for hardware/luxury wellness (Oura). Dated: teal/mint medical gradient, stock yoga photos, Raleway.
- **Education** — Win: white + black pill CTAs + custom friendly sans + interactive demos (Brilliant). Dated: primary-color blocks with cartoon mascots and Comic-adjacent rounded fonts for adult learning.
- **Nonprofit** — Win: cream `#FAF7F0` + one warm saturated CTA (`#FFCA0A`) + photography + Roboto/plain sans (charity: water). Dated: blue+green "hope" palette, three-column icon features, red donate buttons on gradients.
- **Mobile-app marketing** — Win: device mockup scroll-through, app's own screenshots supply color; chrome either dark + serif/mono (Flighty) or cream + saturated primaries + quirky display (Arc). Dated: App Store badge hero with angled phone, purple gradient bg, feature-tile grid with 2-tone line icons.

Cross-cutting 2026 signals: serif-display + mono-label pairings are mainstream; pure `#000` is used but `#08090a`/`#0a0a0a` is more common; off-whites (`#fafafa`, `#f7f7f4`, `#FAF7F0`, `#FFFCEC`) have replaced pure white for light themes; radius clusters at 6px (dev), 8–10px (SaaS/admin), pill (consumer/health), 0px (luxury/agency).

- web-features / Baseline: `https://unpkg.com/web-features@latest/data.json` (4.9 MB; `features{id: name, group, spec, status{baseline: false|"low"|"high", baseline_low_date, baseline_high_date, support{chrome,firefox,safari…}, by_compat_key}}`, 1,231 features); also attached to GitHub releases `https://api.github.com/repos/web-platform-dx/web-features/releases/latest` (assets `data.json`, `data.extended.json`, `data.proposed.json`; v3.44.0). Note: the raw `main` path for data.json is 404 (generated at build).

### Galleries / inspiration — public JSON?
- **Awwwards**: RSS only (above); `/api/v1/sites` 404. **Godly**: no JSON/RSS; Next.js RSC HTML, image items on `cdn.recent.design/items/{id}` (scrape-fragile). **Lapa.ninja, Land-book, SaaSpo**: Cloudflare challenge (403) even for `/feed`, `/sitemap.xml`. **Dribbble**: v2 API requires OAuth and only returns the authenticated user's own shots ([docs](https://developer.dribbble.com/v2/shots/)); `popular.rss` returns empty 202. **Mobbin**: `/api/v1/apps` 401. **Framer/Webflow marketplaces, Tailwind Plus, Vercel templates**: HTML only (Vercel `/api/templates` returns HTML). Conclusion: no stable public JSON; treat these as manual/LLM-browsed sources, not script-polled.

### Color trend sources
- **Pantone**: no API. COTY page `https://www.pantone.com/color-of-the-year` is Next.js HTML; current = PANTONE 11-4201 Cloud Dancer (2026). Scrape the `<title>`/og tags once a year (December).
- **Coolors**: no official API; `coolors.co/api/palettes/trending` returns the HTML app. Third parties only offer scrapers.
- **Adobe Color**: no public API (`color.adobe.com/api/v2/themes` 404); the web tool itself was reorganized in 2025–26.
- **ColourLovers** `api/palettes/top?format=json` now returns an HTML shell (dead).
- Practical substitute: derive trend signal from Google Fonts `trending`, shadcn/Radix/Tailwind token diffs, npm download deltas, and the Awwwards RSS titles.
